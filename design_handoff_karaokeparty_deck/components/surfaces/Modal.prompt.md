The only overlay: Display options, and the room and user editors.

```jsx
<Modal title="Display" onClose={close} buttons={<Button tone="vu" block onClick={close}>Done</Button>}>
  …
</Modal>
```

Solid, not blurred — this brand does not do frosted glass. Title is silkscreen and usually one word. Actions live in `buttons`, stacked full width behind a hairline, amber key first. Sized `maxWidth: 480` and full-width inside the phone gutter.
