The wordmark and mark. Both are CSS geometry — there is no image asset, and you must not draw a mark of your own.

```jsx
<Logo withMark />                          {/* app header */}
<Logo size="2rem" withMark markSize={72} /> {/* sign-in screen */}
<Mark size={28} />                          {/* favicon-scale, mark alone */}
```

KARAOKE sits in `--ink`, PARTY in amber, stacked and tracked at .13em: two channel labels silkscreened on a panel. The mark is the volume knob — concentric circles with an amber index line at twelve o'clock, the same knob the transport uses, which is the point. Never set the wordmark on a light background, never letterspace it differently, never put the two words on one line.
